ByebAI is set up

It's already watching for YouTube's own "Made with AI" labels and hiding that content.

What it does

  • Hides videos in feeds, search results, sidebars, and Shorts shelves that YouTube itself has labeled as made or altered with AI.
  • Blocks the watch page and Shorts player (with an option to override) when a video's "How this was made" panel says the same.
  • Runs entirely in your browser. No video data or browsing history leaves your machine. See the privacy policy.

Known limitations

Only catches what YouTube itself discloses. Undisclosed AI content is invisible to this extension by design; there is no independent detection happening.

English UI only, for now. Detection reads label text, which YouTube localizes, so non-English interfaces won't be caught yet.

YouTube's markup changes. If detection suddenly stops working, it likely needs an update to match a redesign.

This is a free, independent project. If it's useful to you, a donation helps cover the time spent keeping it working as YouTube changes.
